# DSV2-server — сервер и зашифрованная база данных

Репозиторий предназначен для хранения:
- актуальной версии сервера DSV2 (бинарь под Windows);
- зашифрованной резервной копии базы данных (аккаунты, серверы, каналы, сообщения, закреплённые).

Исходников здесь нет — они в основном репозитории `TorgovecFox/DSV2`.
База шифруется (AES-256) перед выкладкой, поэтому файл можно хранить публично:
без пароля прочитать его нельзя. Пароль известен только владельцу сервера.

Обновление содержимого делается скриптом с машины, где запущен сервер.
