# DSV2-server — сервер и зашифрованная база данных

Здесь хранится:
- `server/DSV2.Server-<версия>.exe` — актуальная версия сервера (добавляется скриптом);
- `backup/*.db.enc` — зашифрованные резервные копии базы (см. `backup/README.md`);
- `backup/latest.json` — сведения о последнем бэкапе.

Исходников тут нет — они в основном репозитории `TorgovecFox/DSV2`.
Открытую базу (`*.db`) сюда не коммитим: только зашифрованные файлы.

## Как обновить содержимое

На машине, где работает сервер (в репозитории исходников DSV2):

```
$env:DSV2_BACKUP_PASSWORD = "ваш-пароль"
powershell -NoProfile -ExecutionPolicy Bypass -File tools\publish-server-backup.ps1 -IncludeServerExe
```

Скрипт сделает снимок базы, зашифрует его, положит в `backup/`, (опционально) скопирует бинарь
сервера и закоммитит с пушем в этот репозиторий.
