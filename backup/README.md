# Зашифрованные резервные копии базы

Файлы `dsv2-backup-<дата>.db.enc` — база сервера DSV2, зашифрованная AES-256-CBC + HMAC-SHA256
(PBKDF2-SHA256, 200 000 итераций). Без пароля не читается — файл можно хранить публично.
Пароль известен только владельцу сервера и в репозиторий не попадает.

`latest.json` — сведения о последнем бэкапе (версия сервера, дата, размер и SHA-256**
исходной** базы).

## Как восстановить

1. Скачайте нужный `*.db.enc`.
2. В репозитории исходников DSV2 выполните:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File tools\restore-server-backup.ps1 -File <путь\dsv2-backup-....db.enc> -Out dsv2.db
   ```

   Пароль — из переменной `DSV2_BACKUP_PASSWORD` или параметром `-Password`.
3. Положите полученный `dsv2.db` в каталог данных сервера (там, где сервер ищет базу) и запустите сервер.

Напоминание: открытую базу (`*.db`) в репозиторий не добавляйте — только `*.db.enc`.
